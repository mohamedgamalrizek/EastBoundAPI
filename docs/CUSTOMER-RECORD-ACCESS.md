# إسناد العملاء وصلاحيات رؤية السجلات

- `lead_view_all`: عرض كل الليدز؛ بدونه يكون الوصول حسب `leads.assigned_to`.
- `customer_view_all`: عرض كل العملاء؛ بدونه يكون الوصول حسب `customers.assigned_to`.
- `customer_assign`: اختيار المسؤول في نموذج إضافة أو تعديل العميل، بالإضافة إلى صلاحية الإنشاء أو التعديل اللازمة للعملية.

الفرص المرتبطة بليد وعميل تخضع للقيدين معًا. يمتد الوصول إلى الكوتيشن وأوامر البيع والرحلات والمشتريات المرتبطة، والحجوزات وملفات العميل والفواتير والتحصيل. صلاحية عرض الكل لا تمنح التعديل أو الحذف. قوائم الاختيار والوصول المباشر تخضع لنفس القيود.

العميل الجديد يُسند للمستخدم المحدود تلقائيًا، إلا إذا اختار إسنادًا مصرحًا به. العملاء القدامى غير المسندين يراهم صاحب صلاحية عرض الكل حتى يوزعهم. لا توجد إعادة توزيع تلقائية للبيانات القديمة.

تُمنح الصلاحيات الجديدة للأدوار الإدارية ومدير المبيعات المعروفة عند تشغيل migration. امنح `customer_view_all` و`lead_view_all` للأدوار الأخرى مثل العمليات والمحاسبة إذا كان عملها يستلزم رؤية جميع السجلات. بوابات العملاء والوكلاء تستمر بقواعد الوصول الخاصة بها.

لتطبيق التحديث على بيئة أخرى:

```sh
php artisan migrate --path=database/migrations/2026_11_16_000001_add_customer_assignment_and_permissions.php
```

اختبارات العزل:

```sh
php artisan test --filter='CustomerRecordAccessTest|LeadAccessTest'
```


## صلاحية مستقلة للفرص

`opportunity_view_all` تظهر تحت **Opportunities / Deals → View All**. تمنح رؤية كل الفرص بشكل مستقل عن عرض كل الليدز والعملاء، دون منح صلاحيات تعديل أو حذف أو عرض تفاصيل العميل/الليد نفسه. بدونها، الفرص تتبع مسؤول الليد؛ إذا لم يوجد ليد، تتبع مسؤول الفرصة. هذا يستبدل قاعدة اشتراط الوصول إلى الليد والعميل معًا للفرص المذكورة أعلاه. السجلات التابعة للكوتيشن تستمر في تطبيق الوصول إلى الفرصة.


تحديث صلاحيات الدخول: **View assigned only** (`opportunity_read`) يفتح الصفحة والسایـد بار ويعرض فرص الليدز المسندة للشخص. **View All** (`opportunity_view_all`) يفتح الصفحة ويعرض جميع الفرص. اختيار الاثنين يعني عرض الكل؛ إلغاء الاثنين يخفي الصفحة ويمنع فتحها مباشرة. الإنشاء والتعديل لهما `opportunity_create` و`opportunity_update` مستقلتان. يتم نقل صلاحيات CRM السابقة لهذه الصلاحيات مرة واحدة أثناء التحديث للحفاظ على الوصول السابق.
